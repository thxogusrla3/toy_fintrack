# 주식 차트 & 거래량 매매 기준 정리 (개발용 스펙)

## 1. 목적

이 문서는 이동평균선(5/10/20일선)과 거래량을 기반으로 매수 / 매도 판단 기준을 정의하고, 추후 자동 매매 또는 종목 추천 로직 개발 시 기준으로 사용한다.

## 2. 기본 지표 정의

### 가격 데이터

- 시가 (Open)
- 종가 (Close)
- 고가 (High)
- 저가 (Low)

### 이동평균선

- MA5: 5일 이동평균
- MA10: 10일 이동평균
- MA20: 20일 이동평균

### 거래량

- Volume
- Volume MA (거래량 이동평균, 예: 5일)

## 3. 추세 판단 기준

### 상승 추세 (정배열)

- MA5 > MA10 > MA20
- 캔들이 MA5 위에 위치

### 하락 추세 (역배열)

- MA5 < MA10 < MA20

## 4. 거래량 해석 기준

### 4가지 패턴

1. 상승 + 거래량 증가
   - 강한 상승 (매수 신호)
2. 상승 + 거래량 감소
   - 상승 유지 (보유)
3. 하락 + 거래량 감소
   - 눌림 (매수 후보)
4. 하락 + 거래량 증가
   - 하락 강화 (위험)

## 5. 매매 전략

## 5-1. 눌림목 매매 (로보티즈 유형)

### 조건

- 상승 추세 유지 (MA 정배열)
- 가격이 MA5 또는 MA10 근처로 하락
- 거래량 감소

### 매수 조건

- 양봉 전환
- 전일 고가 돌파
- 거래량 증가

### 손절 조건

- MA10 이탈
- -3% ~ -5%

### 익절 조건

- +5% ~ +8%
- 전고점 도달

## 5-2. 추세 추종 매매 (하이닉스 유형)

### 조건

- MA5 > MA10 > MA20
- 지속적인 상승 흐름

### 매수 조건

- MA5 근처 눌림
- 음봉 후 양봉 전환

### 손절 조건

- MA5 이탈
- -3%

### 익절 조건

- +3% ~ +6%
- MA5 이탈 시

## 6. 거래량 판단 로직 (개발용)

### 거래량 증가 판단

```text
if (현재 거래량 > 최근 5일 평균 거래량 * 1.5)
    → 거래량 증가
```

### 거래량 급증

```text
if (현재 거래량 > 최근 평균 * 2~3배)
    → 의미 있는 수급 발생
```

## 7. 눌림 판단 로직

```text
if (
    가격이 MA5 근처로 하락 AND
    거래량 감소
)
    → 눌림목 후보
```

## 8. 매수 시그널 로직

```text
if (
    눌림목 상태 AND
    양봉 전환 AND
    거래량 증가
)
    → 매수 시그널
```

## 9. 위험 시그널

```text
if (
    가격 하락 AND
    거래량 증가
)
    → 하락 강화 (매수 금지)
```

## 10. 핵심 개념 요약

- 거래량은 절대값이 아닌 상대값으로 판단
- 상승 초입은 거래량 증가
- 눌림은 거래량 감소
- 하락 + 거래량 증가 = 위험
